《流芳百世》互动电子书

使用方法：
1. 保持 index.html 与 assets 文件夹在同一目录。
2. 双击 index.html，即可在任意现代浏览器中离线阅读。

交互：
- 点击页面左右侧、按方向键，或在页面上左右滑动翻页。
- 底部滑块可快速跳页。
- 点击“目录”可查看全部 30 页缩略图并跳转。
- 点击“全屏”进入沉浸式阅读。

摄像头手势模式：
1. 连接网络后，点击右上角“手势”，并允许浏览器使用摄像头。
2. 右下角会显示镜像预览及手部骨架。将手掌移动到预览画面左侧并停留约 0.9 秒，即翻上一页；移动到右侧并停留，即翻下一页。
3. 点击预览右上角“×”或再次点击“手势”可关闭摄像头。摄像头画面不会上传或保存；浏览器仅在本机进行手势识别。
4. 如果浏览器拒绝本地文件的摄像头权限，请在本文件夹中运行“启动本地阅读器.bat”，然后访问提示的本地地址。

本电子书保留原始 PDF 的全部页面视觉内容。

版式动效说明：
- 缩小展示的手工书页面（第 2-29 页）已按纸面四个顶角建立独立翻页框。
- 翻页、折页阴影和下一页显现仅发生在纸面框内；外围黑色留白与页码区保持不动。
- 翻页轴位于书本中央书脊。右页会从书脊自然弯折至左侧，背面接续下一跨页，并保留柔和的纸张阴影。
- 纸张翻动采用角部卷起、对角折线和渐变投影的柔性动画，避免整页硬板式旋转。
- 卷起部分直接使用当前书页的原始图像纹理，并由连续纸肋依次弯曲、回弹，避免出现与原书不一致的通用白纸材质。
- 书页现在由本地打包的软页翻书引擎渲染。它为每张左右书页计算独立的弯曲曲面与动态阴影，保留页面图像的原始质感；无需为此效果联网。
